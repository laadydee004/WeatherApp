# Weather App

A weather application built with HTML, CSS, and JavaScript that allows users to search for cities and view current weather conditions and a five-day forecast.

## Features

- Search for a city to view its weather information.
- Display current temperature and weather conditions.
- Show feels-like temperature, humidity, and wind speed.
- Display a five-day forecast with high and low temperatures.
- Handle locations with multiple search results.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
